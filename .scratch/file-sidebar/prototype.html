Per extension in the literal sense: every extension that exists gets its own mark, with no vocabulary to run out of and no second icon set. It is a value, which is what mono is for, and it is what the reference's badges are actually doing — MD inside a coloured square is a two-letter tag, not a picture.

The objection is that it is the extension said twice, three characters from the end of the name it sits beside. Directories keep the folder glyph, because a directory has no extension and there is something inside this is the fact the name cannot carry.

the argument this overrules, and why

No file-type glyph on any variant. An icon beside the word it denotes is the same claim twice in the narrowest place in the app — and a filename ends in its own extension, which is the badge, already there, costing nothing. Directories get the chevron and nothing else: there is something inside this is the one fact a name cannot carry, and the chevron carries it.
